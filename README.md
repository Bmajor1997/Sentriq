# Sentriq

**AI-Powered Personal & Business Cybersecurity**

Sentriq is a proposed cybersecurity platform for individuals, families and businesses. Unlike traditional antivirus software, its primary purpose is to help people recognize, understand, prevent and respond to cybersecurity threats using AI.

## 1. Personal Cybersecurity

Designed for everyday users, including people with very little technical knowledge.

| Feature | Function |
| --- | --- |
| AI Scam Detector | Analyze suspicious messages, emails and screenshots. |
| Website Safety Checker | Identify potentially malicious websites. |
| QR Code Scanner | Inspect QR code destinations before opening them. |
| Email Analyzer | Identify phishing and social engineering warning signs. |
| Data Breach Monitor | Notify users of known breaches involving their registered email addresses. |
| Password Security | Evaluate password strength locally without transmitting passwords. |
| Device Security | Guide users through device security settings. |
| Identity Protection | Help users recognize and respond to identity theft. |
| AI Security Assistant | Answer cybersecurity questions in plain English. |
| Security Score | Assess a user's security practices and recommend improvements. |
| Family Protection | Help family members recognize scams and improve security. |
| Emergency Response | Guide users through what to do after being hacked or scammed. |

## 2. Business Cybersecurity

Designed primarily for small and medium-sized businesses that cannot afford a dedicated cybersecurity department.

| Feature | Function |
| --- | --- |
| Business Security Dashboard | Centralized overview of organizational security risks. |
| Employee Phishing Detection | Analyze suspicious communications reported by employees. |
| Employee Security Training | Interactive cybersecurity lessons and quizzes. |
| Phishing Simulations | Authorized employee awareness exercises. |
| Domain Monitoring | Monitor company domains for impersonation and exposure. |
| Vulnerability Monitoring | Identify reported vulnerabilities affecting registered software. |
| Incident Management | Document and track security incidents. |
| Security Policies | Generate customized cybersecurity policy drafts. |
| Compliance Assistant | Help businesses understand security requirements. |
| Vendor Risk Assessment | Evaluate third-party cybersecurity risks. |
| Security Reports | Generate weekly and monthly management reports. |
| AI Business Security Assistant | Provide contextual cybersecurity guidance. |

## 4. What Makes Sentriq Different?

Sentriq is built around four fundamental pillars:

| Pillar | Purpose |
| --- | --- |
| Detect | Identify suspicious activity and potential threats. |
| Protect | Strengthen personal and business security. |
| Educate | Teach users how to recognize and avoid threats. |
| Respond | Provide actionable guidance when incidents occur. |

Rather than building another antivirus product, Sentriq helps people determine whether an email, text message, QR code, website or online offer is potentially a scam, while helping individuals, families and organizations improve their security practices.

## 5. Development Roadmap

### Phase 1 — Personal Cybersecurity

Scam detection, email analysis, website checks, QR scanning, AI assistant and security assessments.

### Phase 2 — Advanced Protection

Breach monitoring, security alerts, emergency response, identity protection and security history.

### Phase 3 — Family Protection

Multiple user profiles, family dashboards and shared security alerts.

### Phase 4 — Business Platform

Employee accounts, administrative dashboard, security reports, incident management and domain monitoring.

### Phase 5 — Advanced Business Security

Authorized phishing simulations, compliance assistance, third-party integrations and automated threat monitoring.

## 6. Development Approach

Where practical, reuse existing development experience and infrastructure from Recipeak and Votic, including authentication, AI credit management, camera recognition, subscription infrastructure and automated testing architecture.

Sentriq should be held to a particularly high security standard:

- Encryption of sensitive information.
- Minimal collection and retention of personal data.
- Protection against AI prompt injection in suspicious emails and documents.
- Strict separation of business customer data.
- Verified threat intelligence rather than relying solely on AI judgments.
- Independent security testing.

The app must never guarantee that a website, email or attachment is safe simply because AI did not identify a threat.

Some monitoring features will require third-party security services and licensing.

Architect the platform from day one to support both personal and business accounts, even if the personal version launches first. This will help avoid rebuilding the foundation when expanding into the business market.

The proposed pricing, features and development phases are starting points rather than finalized requirements. This README records the initial product concept; the listed capabilities are proposed, not implemented.
